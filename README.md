# Scuttle

Scuttle is an iOS application for discovering, sharing, and organizing Apple Shortcuts.

Apple Shortcuts enables powerful automation workflows, but finding useful shortcuts is difficult due to fragmented sharing across forums, social media, and personal collections. Scuttle aims to create a dedicated community platform where users can discover, share, and collaborate on automation workflows.

## Current Status

🚧 Scuttle is currently under active development.

The current version focuses on building the iOS application architecture and user experience. Backend services, authentication, and cloud storage are planned for future development.

## Features

### Currently Implemented

- SwiftUI-based iOS application
- Shortcut discovery interface
- Category-based browsing
- Shortcut detail views
- Reusable UI components
- MVVM application architecture

### Planned Features

- User accounts and authentication
- Upload and sharing of Apple Shortcuts
- Search and filtering
- User profiles
- Ratings and favourites
- Shortcut version history
- Community contributions

## Tech Stack

### Frontend
- Swift
- SwiftUI
- Observation framework
- MVVM architecture

### Planned Backend
- User authentication
- Cloud database
- REST API services

## Motivation

Apple Shortcuts has a growing ecosystem of powerful automations, but discovering quality workflows remains difficult.

Scuttle aims to become a central place where users can explore automation ideas, share their own creations, and learn from the community.
